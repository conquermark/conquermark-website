## NOTES FOR DEVELOPER

The following notes summarize the key implementation decisions for this homepage.

**1. Theme Demo to Follow:** Use `https://brighthub.casethemes.net/app-builder-saas/` as the direct layout reference. Map each section above to the corresponding section in that demo.

**2. Color Scheme:** Retain the dark background from the App Builder SaaS demo. Use WebCycle's existing purple brand accent color for all CTA buttons, pills, and highlights.

**3. Screenshots:** All plugin screenshots referenced above come from the plugin's own admin interface. These need to be captured from an installed instance of the plugin and placed in the correct sections.

**4. Sections NOT Required (for now):** Documentation sub-pages, Changelog page, and Installation Guide are excluded from this initial build. Focus is on the homepage and core conversion pages only.

**5. Pages to Build (Priority Order):**
  1. Homepage (this document)
  2. Features page
  3. How It Works page
  4. Pricing page
  5. Download page
  6. Blog (grid layout)
  7. Demo / Sample Report page
